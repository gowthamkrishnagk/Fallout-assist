How a Jira suggestion moves through LangGraph

LangGraph passes the ticket context through these steps. The two evidence branches run in parallel, then join before the suggestion is reviewed.

↓

↓ join
composite_reranker · Rank the evidenceRanks Jira history using retrieval, LLM relevance, and human and automated outcome signals.
↓

Connections

Only administrators can change these values. Secret fields are never displayed; leave them blank to keep the current value, or check Clear to remove it.

TLS uses the Windows/system trust store by default. Set a custom CA bundle path only when your company network requires an additional certificate.
